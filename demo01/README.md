# Demo01

旧方向下的 2D《春江花月夜》灰盒原型，包含异文调查、修复室和灯序玩法。该版本已停止继续开发，仅保留用于技术验证、作品记录和设计追溯。

## 目录

```text
demo01/
├─ UnityProject/  # 旧版 2D Unity 工程
├─ Builds/        # Windows 演示构建
└─ docs/
   └─ archive/
      └─ legacy_spring_river/  # 旧方向设计文档
```

## 入口

- Windows 构建：构建目录不进入 Git，历史试玩包以 GitHub Release 附件为准
- Unity 工程：[UnityProject](UnityProject/)
- 旧设计文档：[归档说明](docs/archive/legacy_spring_river/README.md)

当前新的制作方向不沿用 Demo01 的工程和核心玩法，见 [Demo02](../demo02/README.md)。
