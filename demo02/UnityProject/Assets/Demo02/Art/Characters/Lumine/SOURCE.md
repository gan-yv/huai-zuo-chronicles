# Lumine Main Character

- Character: Lumine / 荧
- Original model rights holder: miHoYo
- PMX modification credited in the source comment: 观海
- Approved local package:
  `demo02/SourceAssets/References/Downloads/Approved/Characters/`
  `【女主角_荧】_by_原神_39fd8673fd145a6c65858227788cb173.zip`
- Source PMX: `demo02/二创/荧.pmx`
- Runtime model: `Models/VIS_Lumine.glb`

The source comment permits model cleanup, weight and expression fixes, color
changes, moderate costume changes, and adding SPA/Toon textures. It forbids
redistribution, extracting parts for other models, sexual content, political
or religious propaganda, graphic horror, personal attacks, and commercial use.

This project treats the asset as an approved local development reference. Do
not redistribute the character model, textures, GLB, or a build containing
them without separate permission from the rights holders.

## Conversion

- `VIS_Lumine.glb` is generated by
  `demo02/tools/art/import_lumine_pmx.py` through Blender 4.2 and MMD Tools.
- The source T-pose/A-pose is retained only as the bind pose.
- Unity bakes the existing Quaternius locomotion, attack, hit, interaction,
  pickup and death actions onto the Lumine skeleton. Runtime retargeting is not
  used.
- The Blender source report is at
  `demo02/SourceAssets/Characters/Lumine/import-report.json`.
