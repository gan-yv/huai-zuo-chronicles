# Open-World Framework

## 目标

《淮左纪事》采用开放世界动作 RPG 的长期框架，参考成熟作品的“系统职责和玩家循环”，
而不是复制其角色、地图、剧情、专属名词、数值、界面或美术。广陵 Demo 仍是第一个
可验证切片，但底层需要能继续扩展到海陵、通州和更多街区。

## 已落地骨架

### 队伍

- `PlayerPartyController` 固定四席，当前由两名角色占用前两席。
- `1`、`2` 直接切换，`Tab` 循环已有成员。
- 当前角色倒下后自动选择下一名仍存活成员。
- 队伍席数写入场景，当前角色索引沿用现有存档字段。

### 角色档案

- `CharacterDefinition` 是 ScriptableObject，记录角色身份、残世印、体力模型、
  能量上限和技能名称。
- `CHR_Repairer`：续印、近战和时空修复。
- `CHR_PathGuide`：途印、游击和探索向导。
- 角色数据与场景控制节点分离，后续可以继续增加海陵、通州角色。

### 探索体力

- 冲刺持续消耗体力，停止消耗后延迟恢复。
- 跳跃后再次按 `Space` 展开滑翔，滑翔期间持续消耗体力。
- 体力耗尽会自动结束滑翔或冲刺。
- 滑翔使用独立临时视觉，场景碰撞和玩法根节点不变。
- 体力不写存档，重新进入时恢复，避免惩罚读档。

### 区域与锚点

- `WorldRuntime` 保存当前城邦、场景、区域和待处理出生点。
- `WorldArea` 负责区域识别，`WorldSpawnPoint` 负责出生点注册。
- `LocalWorldPortal` 在场景内完成街区移动并保留调查、战斗和队伍状态。
- 官署前街默认开放；东关街与彩衣街需要接近锚点按 `E` 记录。
- 解锁状态写入存档，地图节点和快速旅行按钮同步锁定或开放。
- 记录锚点会恢复全队 35% 生命、全部体力并补充少量终结技能量。

### 技能与残世印

- `CharacterAbilityController` 统一处理 `F` 技能和 `R` 终结技输入。
- 技能冷却、伤害、范围、终结技消耗和自愈全部来自 `CharacterDefinition`。
- 修复者使用前方时缝斩击，途印向导使用折行突进；切人后能力组立即切换。
- 普通攻击、技能与终结技都会为当前角色积累终结技能量。
- 技能会给敌人施加当前残世印状态；不同印在短时间内叠加时触发追加伤害。
- 当前只验证“续 × 途”等基础错位组合，尚未建立完整七印相克表。

### 遭遇调度

- `CombatRegistry` 自动登记启用中的战斗单位，锁定、血条、普通攻击和技能共用。
- `WorldEncounterDefinition` 保存激活半径、敌人强度、默认状态和增援链。
- `WorldEncounterZone` 在玩家接近时唤醒敌人，已激活区域不会再次休眠。
- `WorldEncounterDirector` 协调封锁区域与增援区域，未注册的增援会排队等待加载。
- 官署前街封锁留在基础场景；盐仓横街增援位于独立附加场景。
- `WorldAdditiveSceneRegion` 在玩家接近时异步加载，在遭遇完成且玩家远离后卸载。
- 附加场景加载完成并注册遭遇后，导演会自动兑现之前排队的增援请求。
- 异步加载的区域敌人启用后会自动进入统一战斗查询。
- 当前附加场景只复用现有角色预制体、材质和动画，不新增自制美术。
- 已完成遭遇写入世界运行时的流式区域集合，并在存档中保存。
- 东关街巡哨与彩衣街望风已经分别进入 `DongguanPatrol`、`CaiyiLookout`。
- `WorldStreamingDirector` 统一接收预载与进入请求，按紧急程度和距离排序。
- 同一时间只加载一张附加场景，并在场景之间保留加载间隔。
- 每个区域拥有预载、进入和卸载三种半径，避免临门才加载或过早卸载。
- 东关街与彩衣街各有一个流式街区事件，流程为交谈、清除巡哨、返回交付和领取奖励。
- 东关街“纸鸢旧信”把 NPC 交谈、双时间层调查、风廊挑战、途印与修复者协作、
  公开/私密选择和街区后果串成一段完整短支线。
- 遭遇清理状态与事件完成状态分开保存，读档后不会重复刷取。
- 事件奖励复用现有背包物品，NPC 复用现有角色预制体，不新增自制美术。
- 街区事件追踪器把未发现、进行中、可交付和已完成状态同步到案卷、地图与 HUD。
- 事件开始和完成状态都进入世界存档，跨街与读档后继续显示正确进度。
- 战斗反馈统一上报伤害位置、数值、印反应和玩家受伤状态。
- 已有攻击、技能和终结技通过浮动数字与镜头冲击获得更明确的命中反馈。

## 下一阶段

1. 为流式导演增加加载失败重试、异步池和更细的每帧预算。
2. 将现有拾取物和动态环境状态迁移到内容层，并加入区域级持久化。
3. 增加数据驱动的角色成长、信物和续式槽位，但不引入抽卡与付费机制。
4. 扩充七印协同规则、状态图标和敌人抗性，保持原创能力命名与视觉。
5. 在第二章地图制作前完成四人队伍、四类技能与跨街区锚点的战斗回归。

## 边界

- 不复刻《原神》的专有角色、元素名、地区名、剧情节点、界面布局或商业运营系统。
- 当前四席队伍只展示两名真实可玩角色，空席明确标记为待解锁，不使用伪角色填充。
- 美术继续优先复用已经记录许可证的公开素材。
