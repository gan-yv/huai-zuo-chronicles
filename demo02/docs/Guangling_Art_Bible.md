# 广陵美术方向规范 v1

更新：2026-11-22  
适用范围：Demo02“旧街回潮”垂直切片  
状态：首轮美术试装基线

## 1. 目标

广陵不是泛化的古代城镇。视觉应同时表达：

- 运河与盐业带来的商业秩序。
- 官府对城市记录、街名和地权的控制。
- 潮湿、旧木、灰砖和风化灰泥形成的江南质感。
- 现世旧街与另一时间层重叠后的不稳定感。

首轮验收场景为官署前街约 48 米可玩段。目标是形成一张接近最终宣传图的
街道主镜头，同时保留游戏内可读性。

![广陵官署前街美术试点](screenshots/guangling-art-pilot.png)

## 2. 视觉关键词

- **旧而不脏**：使用磨损、水痕和褪色，不依赖随机污渍堆满画面。
- **秩序中的裂缝**：官府街道整体规整，局部门窗、招牌和地面出现失序。
- **低饱和暖灰**：环境以灰、土黄、旧木棕为主。
- **有限朱红**：朱红和铜黄只用于入口、灯笼、印章和重要交互。
- **青灰时间层**：旧时层降低暖色，增加冷雾和纸张、墨迹、旧漆细节。

## 3. 色彩基线

| 用途 | 建议颜色 | 说明 |
|---|---|---|
| 灰泥墙 | `#B9AFA0` | 暖灰，允许带少量黄褐 |
| 深灰砖 | `#625F59` | 用于墙基、牌坊和边角 |
| 旧木 | `#4A3020` | 梁柱、门板和窗框 |
| 黑褐木 | `#241A14` | 阴影结构，不用于大面积墙面 |
| 灰瓦 | `#4B5355` | 偏冷，避免鲜艳蓝色 |
| 街道石 | `#777069` | 低反射、带水痕 |
| 朱红 | `#84251D` | 灯笼、印章和少量布幡 |
| 铜金 | `#B4883F` | 小面积高光，不自发光 |
| 纸张 | `#D8C9AA` | 告示、账册和旧地图 |

画面构成建议：

- 70% 中性墙面与地面。
- 20% 旧木结构和深色轮廓。
- 10% 朱红、铜金、灯笼和交互强调色。

## 4. 建筑语言

### 街段尺度

- 建筑内立面之间宽度：10～12 米。
- 店面开间：3～4 米。
- 建筑层高：2.8～3.2 米。
- 单栋街面建筑高度：5～7.5 米。
- 檐口挑出墙面：0.8～1.2 米。
- 坡屋顶坡度：近似 20～30 度。

### 必备轮廓

- 主檐口和连续的屋顶线。
- 灰色坡屋顶、屋脊和檐口端部。
- 旧木柱、横梁、门板和窗格。
- 石质墙基，避免木墙直接落地。
- 有限数量的遮雨棚和店招。
- 官府建筑使用更宽门面、更整齐柱距和更克制装饰。
- 商铺允许更密集的招牌、货箱和布幡。

### 禁止方向

- 不使用西欧中世纪半木构房屋作为广陵最终建筑。
- 不把蓝、紫、青等灰盒分区色带入正式场景。
- 不堆叠过多层重复招牌、灯笼和布幡。
- 不依赖纯色方块作为主要建筑轮廓。

## 5. 材质规则

- 墙面：2K 灰泥或砖石 PBR，纹理平铺必须按真实米制尺度设置。
- 木材：2K 旧木板，颜色压暗，避免每根梁柱完全同色。
- 屋顶：2K 陶瓦材质压成灰蓝色，纹理方向顺坡。
- 地面：2K 石板或卵石，反射保持低值。
- 金属：只用于饰品、灯笼框架和工具，不制作大面积高金属表面。
- 玻璃：深色低透光，减少复杂透明排序。
- 法线强度从 1 开始，使用截图检查后再调整。

## 6. 角色规则

### 主角

- 轮廓核心：修复工具、记录挎包、便于移动的短衣和腰封。
- 色彩：暖灰、旧蓝或深褐，避免与街景大面积同色。
- 武器和工具在背后或腰间形成稳定识别点。

### 途印伙伴

- 轮廓应比主角更轻、更灵活，使用不同的下摆和肩部造型。
- 可通过当地织物、绳索和地图筒体现向导身份。

### NPC

- 官府：硬挺轮廓、低饱和衣色、印章或封条配件。
- 商人：布匹、算盘、账簿、袖袋和较宽体型。
- 居民：衣物层次更少，颜色更旧，姿态更放松。

只靠剪影也应能区分主角、伙伴、官员、商人和敌人。

## 7. 灯光与镜头

### 现世

- 黄昏主光使用 3000～3800K 暖色。
- 背光或侧光强调屋檐、灯笼和木构轮廓。
- 环境补光保持低强度冷色，避免阴影纯黑。
- 雾从 35～45 米开始，远景在 80～110 米完全弱化。

### 旧时

- 整体色温向 6500～8000K 偏移。
- 保留局部纸张和灯火的暖色点。
- 增加墨迹、旧招牌、不同商货和居民残影。
- 不通过简单降低饱和度代替时间层设计。

### 游戏镜头

- 第三人称镜头高度：2.2～2.7 米。
- 垂直视角：55～60 度。
- 街道主镜头保留近景门面、中景纵深和远景地标。
- 对话镜头优先利用门洞、檐口和灯笼形成前景遮挡。

## 8. 性能预算

目标平台：Windows x64，1080p 中等画质。

每个约 50 米街段的首轮预算：

- 不透明 Draw Call：不超过 300。
- 投影物体：不超过 180。
- 同时可见三角形：不超过 150 万。
- 唯一材质：不超过 20。
- 纹理总预算：不超过 512 MB。
- 阴影贴图：主光 2K，局部点光默认关闭阴影。
- 中远景建筑必须准备 LOD 或简化版本。

预算不是延迟优化的理由。每次增加 10 米内容后都应记录一次表现。

## 10. 首轮验收

官署前街美术试点至少满足：

- 一张 1280×720 的正常游玩视角截图。
- 街道两侧具有连续屋顶线和至少两种立面变化。
- 墙、木、瓦、石、灯笼和店铺信息可以清楚区分。
- 主角在街景中具有足够对比度。
- 现世与旧时有明确色彩和物件差异。
- 没有明显材质拉伸、悬浮模型、黑块或错误法线。
- 场景达到性能预算，并保留独立测试场景。

本轮试点只验证风格和管线，不替代正式角色、动画和最终建筑套件。

## 12. 角色比例与剪影试点

![主角、途印伙伴与官差角色代理](screenshots/guangling-character-showcase.png)

首轮角色代理使用 1.7 米左右的人体比例，验证以下内容：

- 主角使用深蓝衣身、铜金腰封、记录包和背负修复工具。
- 途印伙伴使用较短的绿色外套、地图筒、斜挎带和非对称轮廓。
- 官差使用长朱衣、官帽、宽袖和腰间印记。
- 每个角色预制体都分离 `Visuals`、`Colliders`、`Gameplay` 和 `Metadata`。
- 角色预制体带独立胶囊碰撞尺寸，便于按真实身高验收。

这些代理是造型方向测试，不包含正式面部、布料、骨骼和动画。正式模型接入时
可以保留当前根节点、碰撞和内容分组，只替换 `Visuals`。
