# Engineering Checklist

## 稳定基线

1. 确认 Git LFS 可用；素材压缩包不进入普通 Git。
2. 确认 `demo02.rar`、`Builds`、`Library`、`Temp` 和缓存目录不进入提交。
3. 执行编辑器全量校验：`Demo02.Editor.Demo02GreyboxBuilder.VerifyAllForBatch`。
4. 构建 Windows x64，并检查 BuildInfo 中的版本、场景列表和结果。
5. 检查存档、显示模式、流式区域和街区事件状态。

## 发布前

- 使用实际显示器分辨率做一次性能采样。
- 分别验证无边框全屏和窗口化。
- 验证主线和两个街区事件从开始到完成。
- 验证保存、退出、重载后敌人数、事件阶段和续式槽位正确。
- 检查第三方素材清单、来源和许可证。
- 生成 ZIP，排除 Burst 调试目录，附带 CREDITS、架构和开放世界文档。

## 美术替换

1. 先替换一个街区的建筑、屋顶和店面。
2. 保持玩法根节点、碰撞和交互组件不变，只替换预制体下的视觉节点。
3. 采样三角面、贴图、Draw Call、阴影和 1% Low。
4. 通过后再批量替换其他街区。
