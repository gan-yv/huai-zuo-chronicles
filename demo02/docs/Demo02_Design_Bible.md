# 《Demo02》设定总纲

版本：1.0
更新：2026-11-20
状态：世界观与叙事基线
用途：统一广陵 Demo 及后续海陵、通州、终章的世界规则

本文合并了原“主世界观、世界历史、江海城市群、长期主线、残世印体系”五份文档。本文描述开发者掌握的设定真相，不代表玩家一开始就知道全部内容；专有名称仍可在测试后调整。

## 1. 核心

一名来自异世界的时空修复者，被针对世界接缝的破坏卷入一个由多个时代拼接而成的城邦世界。他必须追查溯世会，稳定三座核心城市的时锚，并决定修复这个世界，还是利用裂缝回家。

作品的核心问题：

> 当一段历史建立在另一段历史的消失之上，谁有资格决定哪一段历史继续存在？

## 2. 制作范围

### 当前 Demo

- 只制作广陵城内的一片开放街区。
- 包含探索、街区故事、实时战斗、时空修复和一次有持久影响的选择。
- 不依赖海陵、通州和终章才能成立。
- 当前工作标题为“旧街回潮”，具体内容见 [Demo02_Production.md](Demo02_Production.md)。
- 共主、溯世会首领、外国资本和异族的完整真相暂不解释。

### 长期主线

- 正篇暂按广陵、海陵、通州和终章特殊地图四章规划。
- 三座核心城市分别对应一处主时锚。
- 每座城市是一张大章节地图，内部再划分关键街区和短故事。

### 世界背景

- 正篇之外还有金陵、姑苏、临安、明州、松江等城邦。
- 当前只通过人物、书信、贸易、外交、难民、军队和传闻影响广陵。
- 城市数量服从故事需要，不与七道残世印一一对应。

## 3. 世界规则

### 关键名词

以下名称均为工作名。

| 名词 | 含义 |
|---|---|
| 原纪 | 历史断裂之前，按正常顺序延续的时代与世界 |
| 断纪 | 多个时代被折入同一现实的灾难 |
| 叠世 | 断纪之后形成、由多个时代相互重叠的当前世界 |
| 时缝 | 不同时代或空间发生错误交叠的区域 |
| 时锚 | 固定城市时间层、阻止现实互相覆盖的结构 |
| 主时锚 | 维持叠世与通往原缝的三处核心锚点 |
| 次级锚点 | 其他城邦用于维持本地稳定的小型锚点 |
| 原缝 | 断纪发生处，也是三处主时锚最终交会的源头 |
| 残世印 | 七个失落文明被断纪抹去后留下的力量残余 |
| 续印 | 主角跨越世界接缝时形成的特殊残世印 |

### 历史时间线

1. **原纪**：多个文明、地区和国家按照各自的历史顺序存在。七个小文明分别围绕守望、道路、战争、记录、生长、消逝和平衡建立社会。
2. **断纪**：跨越多个时代的灾难使历史层互相塌缩，过去、现在与部分未来被折入同一现实。七个旧文明从连续历史中被抹去，世界也出现了通往其他世界的裂缝。
3. **缝合与重建**：幸存者将三个稳定时间层固定在广陵、海陵、通州所在区域，形成三处主时锚。其他地区随后建立次级锚点并形成城邦，“共主”制度也在这一时期出现。
4. **当前危机**：主时锚周期性失稳，异族从薄弱时缝入侵。官府隐藏断纪真相，溯世会试图拆开时锚，主角则带着损坏的修复工具和续印闯入世界。

### 三处主时锚

| 城市 | 主时锚 | 固定的内容 | 副作用 |
|---|---|---|---|
| 广陵 | 名籍 | 姓名、户籍、官职、契约与官方历史 | 官方可以删改记录，并借此隐藏旧街、旧人口和旧王朝 |
| 海陵 | 流通 | 港口、航道、货物与跨时代交换关系 | 贸易和资本会利用时间差异制造不稳定利润 |
| 通州 | 边界 | 城墙、关隘、军防与外部空间 | 边城必须长期承担最直接的人员和资源损耗 |

- 三处主时锚共同形成通往原缝的稳定路径，缺一便无法安全接近原缝。
- 三锚同步失败时，可能出现道路错位、军队被送回错误时代或整片街区被另一段历史覆盖。
- 次级锚点只能维持本地稳定，不能代替主时锚。

### 共主与城邦

- 各城拥有独立官府、税制、军备和地方利益，不存在统一行政体系。
- 所有城邦公开承认共主，并共同维护三处主时锚。
- 共主不是直接管理地方的皇帝，其核心权柄是主持三锚同步，并拥有开启主锚联合结构的合法权柄。
- 共主之位空缺或失去同步能力时，三锚可能依次失稳，因此各派系即使争夺影响力，也不会公开推翻共主制度。
- 共主的年龄、身份、身体状况和真实立场尚未确定。

### 世界真相

- 拼接世界不是自然形成，而是灾难中为了保住幸存者采取的措施。
- 修复时空不能回到过去，也不能撤销已经发生的事件、死亡和选择。
- 时锚失稳时，人的经历、身份和社会关系可能被另一段历史取代。
- 官府承认“旧年遗迹”和时空异常存在，却隐藏断纪的真正原因。
- 现存秩序将拼接后的世界描述为唯一合法的历史。
- 溯世会认为拼接世界是错误，试图恢复断裂前的时代；部分成员来自被覆盖、被遗忘或失去归属的旧时代。
- 主角自己的世界也受到同一场断裂影响。原缝失控时，即使找到归途，也可能失去可以返回的家园。

## 4. 势力与技术

### 主要势力

| 势力 | 目标与资源 | 与主线的冲突 |
|---|---|---|
| 官府 | 掌握制式火器、时锚管理权、城防和合法历史解释权 | 维持秩序，同时掩盖断纪真相 |
| 商帮 | 盐商、海商等跨城经济集团，拥有资金、商路和短枪 | 追求利润与自治，可能利用时缝资源 |
| 地方实力派 | 家族、军头、行会和街区势力 | 争夺土地、人口、防务和地方权力 |
| 外国资本 | 来自断纪影响较轻的地区，技术与金融、军备更先进 | 希望维持可控制的不稳定市场，不追求恢复原纪 |
| 异族 | 来自外围或时缝另一侧，以冷兵器和近身冲击为主 | 利用时缝薄弱处入侵，具体动机待定 |
| 溯世会 | 掌握裂解时锚、操纵时缝和利用蚀印的方法 | 拆开三处主时锚，恢复旧时代 |

### 溯世会

- 采用分散潜伏的细胞式组织，不设公开总坛。
- 一部分成员是失落文明遗民的后代，一部分是被档案删除、失去身份或故乡的人。
- 他们不认为自己是在毁灭世界，而认为自己在结束一场持续太久的灾难。
- 他们隐藏在官府、商帮和地方势力之间，利用现实矛盾招募成员。
- 与外国资本有交易，但双方目标不完全一致。
- 首领身份、最终目标以及与共主和主角的关系尚未确定。

### 技术与时代

- 背景融合隋唐、明、清与近代元素，属于架空设定，不对应单一真实朝代。
- 火器处于初级阶段。官府使用统一制式火器，商帮和地方势力使用零散短枪，外国资本装备更先进。
- 异族以冷兵器和近身冲击为主要战斗风格。
- 不追求历史复原，优先保证各时代制度、器物、审美和权力关系组合后具有内在逻辑。

## 5. 时空修复与残世印

这是两套完全独立的系统。

### 时空修复

- 主角的职业能力，依赖专用工具、程序和现场条件。
- 只在关键时缝、时锚或时空结构处发挥作用。
- 用于调查异常、稳定空间、开启通路和推进主线，不作为普通战斗技能使用。
- 不能回退时间、复活死者或撤销选择，只能稳定当前结果并阻止异常扩大。
- 标准流程为：辨层、寻找接点、对齐并合层。
- 修复可能需要借助残世印或伙伴接近关键位置，但残世印不能直接完成修复。

### 七道残世印

残世印不是单一技能，而是失落文明理解世界、组织生活和面对时间的方式。共鸣者可以获得一整套相关能力，但不同人物可以有不同职业和表现。同一座城市可以拥有多种残世印使用者。

| 残世印 | 核心主题与视觉 | 战斗与探索 | 社会意义 |
|---|---|---|---|
| 镇印 | 存续、边界、守护、誓约、秩序与重量；古石、城砖、铜印 | 护盾、阻挡、反击、固定战场；固定道路、开启封印、辨认契约 | 官府和守城者推崇，商帮也会用契约约束敌人 |
| 途印 | 道路、迁徙、探索、交易与自由；车辙、路标、残影 | 高速切入、后撤、追击、改变敌我距离；打开捷径、追踪目标 | 商帮、信使、流民和向导广泛使用 |
| 烽印 | 战争、勇气、锻造、牺牲、号令与集体行动；战旗、鼓点、锻炉 | 强攻、破阵、鼓舞、爆发；震开障碍、唤醒守卫器械 | 军队和地方实力派偏爱，也能用于制造权力 |
| 镜印 | 记忆、身份、真相、伪装与重复；碎镜、倒影、旧影 | 复制攻击、反射、识破、影身；读取残影、辨认伪装 | 官府用于审案，商帮用于伪造或识破身份 |
| 芽印 | 生长、疗愈、延续、乡土与供养；嫩芽、根系、愈合裂痕 | 治疗、持续恢复、束缚、保护；让道路和居民区复苏 | 医师和农户信任，官府却担心它削弱迁移命令 |
| 蚀印 | 衰败、遗忘、隐匿、吞噬与结束；灰烬、褪色字迹 | 削弱、隐身、腐蚀、切断能力；让监视者忽略道路 | 官府视其为危险能力，失序者依靠它生存 |
| 衡印 | 平衡、因果、连接、判断与代价；丝线、天平、悬停碎片 | 连接、转移、锁位、重排距离；连接空间、稳定机关 | 常用于调停和裁决，也容易被权力操纵 |

通用边界：

- 残世印是战斗与探索能力，不能替代时空修复工具。
- 残世印可以暂时改变距离、位置或局部状态，不能永久修复主线中的时缝。
- 印不代表善恶，也不与城市一一绑定；官府、商帮、地方势力、外国资本和异族都可能拥有共鸣者。
- 每道印都需要同时具备视觉语言、战斗能力、探索用途和社会意义。
- 暂不建立完整相克表，优先设计少量清晰的时间状态组合和队伍协同。

### 续印与续式

续印不属于七个失落文明，是主角穿越世界接缝时留下的独特残世印。

- 核心概念：延续、承接、兼容，以及保存本会消失的能力片段。
- 视觉：没有固定颜色的金白刻痕，承接能力时会短暂染上对应残世印的纹样。
- 主角拥有自己的近战方式、核心技能和大招，不因修复职业而被限制为辅助角色。
- 主角在关键剧情中理解并接纳其他能力者的经历后，可以保留对方能力的一个“续式”。
- 续式拟限制为同时装备两个，不能复制完整能力、终极大招或角色身份。
- 续式来自人物关系、城市故事和关键选择，不通过击杀、刷取或随机掉落获得。
- 续式可用于战斗和有限的探索解法，但不能替代修复工具。
- 续印不是天命继承。它更像一份不稳定的能力记录，其他势力也会试图夺取或利用它。

## 6. 主角

- 来自异世界的低阶时空修复者。
- 不是无敌战士，也没有统领军队的身份；普通冷兵器或初级火器仍能威胁他。
- 正面作战依赖残世印和续式，可以成为强力战斗者。
- 闯入事件与时缝破坏有关，修复工具在过程中受损。
- 找到并校准原缝是回家的必要条件。
- 不愿轻易相信任何一个势力。
- 姓名、性格、原本生活与私人执念仍待确定。

## 7. 城市体系

每座城市都必须回答三个问题：

1. 这座城市主要代表什么观念？
2. 这种观念如何体现在城市结构和日常生活中？
3. 为了维持这种观念，城市牺牲了谁？

### 三座主城

| 城市 | 主题 | 核心冲突 | 时缝与能力倾向 |
|---|---|---|---|
| 广陵 | 正统与秩序 | 官府、盐商和旧街居民争夺“正确历史”的解释权 | 旧官署和档案重叠；镇印、镜印较多 |
| 海陵 | 流动与交易 | 城市依赖跨时代贸易，却因此越来越不稳定 | 不同年代的船只和码头交汇；途印、衡印较多 |
| 通州 | 边疆与牺牲 | 共主和官府优先保护时锚，边城承担最大损耗 | 战场、城墙和无人区反复错位；烽印、镇印较多 |

### 世界层城市

| 城市 | 主题 | 主要矛盾与作用 |
|---|---|---|
| 金陵 | 旧权与记忆 | 旧宫城、陵墓和档案库争夺被遗忘的历史；暗示旧时代并非溯世会虚构 |
| 姑苏 | 技艺与乡土 | 行会、家族和外来资本争夺技艺与土地；展示普通人如何继续生活 |
| 临安 | 繁荣与幻象 | 娱乐与消费繁荣，底层居民却被时间层吞没；为溯世会提供追随者 |
| 明州 | 开放与边界 | 港口、外国商馆与守军围绕开放和安全冲突；连接外国资本和异族威胁 |
| 松江 | 资本与革新 | 新式工场、钱庄和报馆推动技术，也被资本控制；展示更先进的生产和军事力量 |

### 城市关系

- 各城公开效忠共主，地方官府拥有很大自主权。
- 盐商、海商和外国资本跨越城市边界活动，经济权力不受单一辖区限制。
- 溯世会可以潜伏在多座城市，借用不同矛盾推进计划。
- 异族主要从通州和明州方向施加压力。
- 难民、商路、粮价、军备和情报会把一座城市的危机传给其他城市。
- 当前不制作海陵、通州、金陵、姑苏、临安、明州和松江的可探索地图。

## 8. 长期主线

主角必须先稳定广陵、海陵、通州的三处主时锚，才能抵达终章的原缝。三锚不是可简单收集的物品，而被当地官府、商帮、地方势力或外部力量控制或争夺。

主线信息分三层推进：

1. 城市层面的时缝灾害与政治冲突。
2. 溯世会如何利用当地势力制造破坏。
3. 拼接世界为何形成、共主隐瞒了什么，以及原缝能否同时保住两个世界。

### 四章结构

| 章节 | 表层事件 | 核心揭示 | 章节选择 | 章末线索 |
|---|---|---|---|---|
| 广陵：被规定的历史 | 被删除的旧街在黄昏后重新出现 | 城市秩序建立在删改历史之上，溯世会已进入官府 | 公开真相动摇官府，或隐瞒真相维持秩序 | 破坏者留下通往海陵的时缝标记 |
| 海陵：被出售的年代 | 港口、仓库和商船在不同年代错位 | 溯世会以“恢复故乡”招募被时代吞没的人 | 关闭贸易通道保住城市，或保留通道扩大裂缝 | 行动指向通州边境 |
| 通州：被牺牲的边城 | 异族利用时缝入侵，地方势力争夺防务 | 共主一直以牺牲边地维持核心城邦稳定 | 保住时锚可能牺牲居民，救人则可能让原缝失控 | 三锚的稳定方式决定原缝的结局 |
| 终章：原缝 | 三城时空结构交会，所有矛盾集中爆发 | 主角必须面对共主、溯世会和被吞噬的历史 | 缝合、拆开或利用接缝回家 | 决定哪些历史和人能够继续存在 |

### 结局方向

- **缝合原缝**：保住三城与居民，但关闭主角回家的通路。
- **拆开接缝**：支持恢复旧时代，现有核心城市的部分居民和历史将被覆盖。
- **利用接缝回家**：主角返回自己的世界，三城独自承担失控后果。

具体结局数量、触发条件和是否存在第三方案尚未确定。

### 玩家认知阶梯

1. 广陵：发现时缝不是单纯自然灾害，官府知道并掩盖其存在。
2. 海陵：发现溯世会利用现实矛盾招募成员，外国资本也在争夺时缝资源。
3. 通州：发现共主维持秩序的方法包含牺牲，主时锚接近失稳。
4. 原缝：理解断纪与叠世的全部真相，并在原纪、叠世与归途之间选择。

当前 Demo 只需到达第一层。

## 9. 游戏结构

- 剧情驱动的 3D 城市开放区域冒险。
- 采用第三人称实时战斗，不在探索与战斗之间切换独立场景。
- 每座城市在叙事体量上替代传统开放世界中的“国家”，当前只制作有限街区。
- 玩家最多携带三名角色并在战斗中切换；角色通过剧情加入，不使用抽卡。
- 每名角色拥有普通攻击、闪避、技能、终极大招和被动能力。
- 战斗出现在关键剧情、伏击、追逐和冲突节点，不设置反复刷新的敌人营地。
- 不设置封锁区域的隐形墙。敌人可以追击到相邻街道，巡逻队和援军也可以加入。
- 大型战斗通过职责、位置和攻击意图控制可读性，而不靠禁止敌人出现来限制规模。
- 探索奖励以证词、通行权、人物关系、捷径和城市状态变化为主。
- 战斗结果会改变巡逻、商铺、NPC 态度和可进入区域。

## 10. 硬规则

- 不回到过去，不撤销死亡，不让玩家重选已经发生的结果。
- 时空修复必须与战斗能力分离，修复工具不能当作战斗技能。
- 残世印不能直接修复主时缝，只能暂时改变空间、位置或战斗状态。
- 世界中存在多名能力者，主角不是唯一的超常力量拥有者。
- 七道残世印来自失落旧文明，不与当前城市一一绑定。
- 同一城市可以拥有多种残世印角色和不同社会立场。
- 当前 Demo 只制作广陵，不因世界观扩展而增加其他可玩城市。
- 不复制既有作品的角色、剧情、专有名词、视觉、音乐和具体技能。

## 11. 明确排除

- 不以宣传现实扬州或江南文化为目的。
- 不复用《春江花月夜》、古诗异文、现代文献修复师和旧校勘系统。
- 不使用三城灯汛、永昼、时间循环和重复梦境。
- 不直接复制其他游戏的角色、剧情、术语、视觉、音乐或具体技能。
- 不做抽卡、日常任务、体力系统和持续运营。

## 12. 待确认

- 主角姓名、性格、原本生活和私人执念。
- 共主身份、真实立场，以及其与断纪的关系。
- 溯世会首领及其与主角的个人联系。
- 三座城市的具体地理、经济与地方实力派。
- 三处主时锚的具体形态和稳定方式。
- 外国资本、异族与溯世会的具体关系。
- 异族入侵的动机和政治结构。
- 七道残世印的组合规则，以及是否存在人造印、跨印者或禁忌之印。
- 终章结局数量、触发条件和第三方案。
