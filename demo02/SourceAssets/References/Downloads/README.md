准入要求：

1. 保留作者、来源页面、许可证和原始压缩包。
2. 确认允许修改、商业使用和再分发。
3. PMX、MMD 舞台或未授权游戏提取资源不得导入 Unity。
4. 导出 Unity 所需格式后，只复制实际使用的文件到 `Assets/ThirdParty/`。
