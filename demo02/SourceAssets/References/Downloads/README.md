使用要求：

1. 保留作者、来源页面、授权记录和原始压缩包。
2. 从 PMX/Blend 导出 Unity 所需格式时，只转换实际使用的对象。
3. 只复制运行所需文件到 `Assets/ThirdParty/`，不复制临时工程。
4. 在游戏署名和仓库 `CREDITS.md` 中记录实际使用的作者与素材名。
