# 《春江花月夜：异本》整体游戏逻辑与状态系统

版本：0.1  
用途：统一主线、三卷结构、Demo 和结局判定逻辑  
原则：选择必须可理解、可追踪、会留下具体后果，不使用隐藏道德分数

## 1. 三层游戏逻辑

整体游戏由三层组成。

### 1.1 世界压力层

城市面临的问题是：

- 运河旧秩序衰落。
- 铁路和海港正在重分权力。
- 外部势力把联市拖向战争。
- 三座城市对自由、统一和传统有不同理解。

玩家不管理整个世界，只承受它施加在具体人物和文本上的压力。

### 1.2 认知层

玩家通过调查获得不完整信息：

- 只能先问部分证人。
- 每个人掌握一部分真相。
- 不同的信息来源改变玩家对异文的理解。
- 错过的信息不会自动补齐。

玩家在这里做的是“选择和谁交谈”，不是收集全图鉴。

### 1.3 编辑层

玩家决定文字如何进入城市：

- 选择哪个异文。
- 选择保留什么注释。
- 选择通过何种方式传播。
- 最终决定残本如何修复。

这是本作的核心玩法，也是叙事后果的来源。

## 2. 单章核心循环

每一卷都执行同一套循环：

```text
发现异文
  ↓
选择调查对象
  ↓
获得证词与人物处境
  ↓
选择异文或注释
  ↓
选择传播方式
  ↓
看到即时后果
  ↓
写入校勘记录
  ↓
进入下一城市
```

单章内最多包含：

- 1次主要调查取舍。
- 1次文本或解释选择。
- 1次传播选择。
- 1次章节结果。

不在一章里同时增加战斗、经营、跟随潜行和数值升级。

## 3. 校勘记录

### 3.1 定义

“校勘记录”是玩家从异本带回现实、并会带入后续章节的页面。

它既是核心存档状态，也是玩家理解自己选择的主要界面。

记录展示的是具体决定，不是抽象的善恶值：

- 这一段原本缺了什么。
- 玩家采用了哪个版本。
- 证据来自谁。
- 这个版本通过什么方式传播。
- 哪个群体被写入了公共记忆。
- 哪个问题仍然没有答案。

### 3.2 界面呈现

校勘页是一张可以随时打开的双页纸：

- 左页：原诗、缺字和异文。
- 右页：证词、印章、传播记录。
- 页边空白：玩家可以查看尚未解决的疑问。

每完成一卷，新增一页或一栏。终章时，三城记录合在同一张长纸上。

### 3.3 数据记录

每座城市生成一条 `CityRecord`：

```json
{
  "city": "yangzhou",
  "witness": "printer",
  "variant": "zhao",
  "transmission": "print",
  "annotation": "rescue_signal",
  "truthKnown": false,
  "missedWitness": "performer"
}
```

正式版本可以增加多个证物或注释，但保留同一核心结构。

### 3.4 记录的作用

- 决定终章时可以引用的证词。
- 决定哪些人物在尾声中出现或沉默。
- 决定最终长卷上保留哪些版式。
- 帮助玩家在停玩一段时间后回忆自己做过什么。

它不直接换算成“正义值”“文化值”或“城市繁荣度”。

## 4. 三类选择

### 4.1 调查选择

问题：先听谁说话？

- 选择一位证人，获得其证词和具体处境。
- 另一位证人保留为未解问题。
- 玩家可能通过后续书信得到部分补充，但不能补全全部信息。

调查选择的重点不是“谁说的是假的”，而是“谁的真相进入了你的判断”。

### 4.2 编辑选择

问题：哪一种文字进入节目的正文？

- 选择异文。
- 选择是否加校注。
- 选择把空白视为错误还是有意保留。

编辑选择必须改变人物行动或公共仪式，而不只是改变结局文本。

### 4.3 传播选择

问题：这段文字给谁看、怎样看？

传播方式有四种：

| 方式 | 优点 | 代价 |
|---|---|---|
| 印刷 | 覆盖广、可长期保存 | 一经发出难以收回 |
| 口述/唱词 | 保留语气和现场关系 | 容易失传或被再次改变 |
| 电报 | 速度快、能跨城 | 字数有限、丢失细节 |
| 灯火 | 全城同时看见、具有公共仪式性 | 容易被所有人同时误读 |

每卷只让玩家集中处理一种传播冲突，避免四种方式都变成菜单。

## 5. 三卷的逻辑分工

### 5.1 扬州卷：谁有权定本

- 主要冲突：官方节目册与地方口传。
- 核心选择：正文用“待”还是“照”。
- 传播冲突：印刷。
- 玩家第一次体验“一经印出无法收回”。

### 5.2 海陵卷：记忆是否必须变成文字

- 主要冲突：口传记忆与可保存的档案。
- 核心选择：记录完整唱词，还是保留只有现场才能成立的版本。
- 传播冲突：手抄/印刷与口述。
- 玩家看到“保存”也可能改变一种活着的传统。

### 5.3 通州卷：统一是否等于和平

- 主要冲突：地方异文与标准化电文。
- 核心选择：接受统一版本，还是保留地方校注。
- 传播冲突：铁路、电报与大众印刷。
- 玩家看到“传播更快”可能让一种解释先占据所有城市。

## 6. 即时后果

每个选择必须至少在以下三项之一产生变化：

1. 某个人对玩家开放或关闭信息。
2. 某条路线、船只或会场可以进入。
3. 下一场的公共文本或仪式内容发生变化。

只在最终总结页显示“你选择了A”，不算有效后果。

即时后果建议使用：

- 一段短对白。
- 一张静态场景变化。
- 一件证物被盖上或销毁。
- 一条路线被点亮或关闭。

## 7. 终章逻辑

三卷完成后，玩家拥有三城校勘记录。终章不进行新的长时间调查，而是让玩家处理已经积累的文本：

1. 查看哪些证据已经掌握。
2. 决定三城灯会使用哪一种版本组合。
3. 决定对外发出的灯序。
4. 回到现代修复室，处理残页的最后空白。

终章的核心不是“击败反派”，而是把玩家塑造的文本放到所有人面前。

## 8. 结局判定

### 8.1 不采用隐藏分数

游戏不计算：

- 正义值。
- 文化纯正度。
- 城市现代化指数。
- 玩家是否收集全部证物。

结局主要由最后明确选择决定，前文选择改变结局的细节、人物命运和文本内容。

### 8.2 三个主要结局

玩家在终章选择：

- **定本**：填上一个字，指定唯一正文。
- **合本**：并列保留各城版本和校注。
- **残本**：保留空白，只记录发现、差异和未能确认的部分。

前一卷的选择决定：

- 谁在校勘页上留下印章。
- 哪些证词能在终章被引用。
- 三城在灯会上的对应反应。
- 尾声里修复师最终完成了什么、放弃了什么。

### 8.3 结局质量原则

三个结局都必须：

- 能完整结束故事。
- 回答残本为何缺字。
- 给出城市未来的明确方向。
- 保留不同群体的代价。
- 不依赖玩家猜中某个隐藏数字。

## 9. 失败与继续

游戏没有传统失败页。

判断错误会导致：

- 某个人拒绝继续帮助。
- 某段文字被提前发表。
- 某条船离开或某场灯会停办。
- 某个版本失去被公共承认的机会。

故事继续推进，玩家必须面对后果。

## 10. Demo1 在整体逻辑中的位置

Demo1不是独立小游戏，而是完整逻辑的最小切片。

### 覆盖的系统

- 发现异文。
- 调查二选一。
- 证据改变解释。
- 异文选择。
- 印刷作为不可收回的传播方式。
- 即时结果。
- 写入校勘记录。

### 暂不覆盖的系统

- 海陵和通州。
- 口述、电报和灯火传播。
- 终章。
- 最终修复方式。
- 多轮章节存档。

### Demo1写入的状态

```json
{
  "city": "yangzhou",
  "witness": "printer_or_performer",
  "variant": "dai_or_zhao",
  "transmission": "print",
  "annotation": "partial",
  "truthKnown": false,
  "missedWitness": "the_other"
}
```

Demo结束时必须展示这张不完整校勘页，让玩家看到：

- 这是我选择的字。
- 这是谁让我作出这个选择。
- 我失去了另一条证词。
- 这一页将进入后续城市。

## 11. 为什么这样设计

### 避免纯视觉小说

玩家不只是选择对白，而是选择文字如何进入公共世界。

### 避免猜正确答案

两种版本都有社会代价，证据决定的是理解深度，不是标准答案。

### 避免结局与前文脱节

终章使用的是玩家亲手建立的校勘记录，而不是突然出现的选择题。

### 避免系统膨胀

核心状态只有证人、版本、传播和注释，不增加城市经营和数值培养。

## 12. 明确禁止新增的系统

- 善恶值。
- 角色好感度刷取。
- 多货币经济。
- 装备和等级。
- 随机卡牌战斗。
- 开放世界跑图。
- 与文本和传播无关的收集率。
- 为每个城市单独制作完全不同的小游戏。

三卷可以改变场景、人物和传播冲突，但必须回到同一套逻辑。
