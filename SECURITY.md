# Security Policy

## Supported Versions

Security and data-loss fixes are prioritized for the latest stable release.

## Reporting a Vulnerability

Please report vulnerabilities privately through GitHub Security Advisories when
available, or contact the repository owner without publishing exploit details.

Relevant reports include:

- Path traversal or unsafe archive handling.
- Save-file corruption or unintended data deletion.
- Secret or credential exposure.
- Remote code execution through imported content.
- Third-party dependency vulnerabilities that affect release builds.

Please include the affected version, reproduction steps, impact and any suggested
mitigation.
